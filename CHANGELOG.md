# Changelog

All notable changes to this project are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/).

## [1.0.0] - 2026-11-18

### Added
- Bilingual portfolio (EN/DE) with automatic browser-language detection.
- Dark mode with saved preference and no flash on load.
- All content loaded from JSON files in `public/data/`.
- Sections: hero, about (flip cards), toolbox, experience timeline, projects (filterable), smile break, contact.
- Bugsy the mascot: eye-tracking, moods, compliments and confetti.
- Typewriter headline, scroll-reveal animations, toast messages, smile counter.
- Konami-code easter egg (party mode).
- Reduced-motion support and keyboard/screen-reader friendly controls.
- Unit tests (Vitest), including an EN/DE data-consistency check.
- GitHub Actions workflow for testing and deploying to GitHub Pages.
- Documentation: architecture, SOLID, data guide, deployment, coding conventions.
